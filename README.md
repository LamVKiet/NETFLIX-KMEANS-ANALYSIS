# NETFLIX ANALYSIS AND RECOMMENDATION SYSTEM
This project focuses on data visualization and analysis of movies and shows from the Netflix Movies and TV Shows dataset available on [Kaggle](https://www.kaggle.com/datasets/shivamb/netflix-shows)

For more details about the project, please visit the full text at: [Netflix Analysis and Recommendation System](https://github.com/LamVKiet/NETFLIX-KMEANS-ANALYSIS/blob/main/Report_Netflix%20Analysis%20and%20Recommendation%20System.pdf)

## Project Tasks:
- Preprocess, visualize, and analyze Netflix movie and show data.

- Apply the K-Means clustering algorithm to uncover deeper insights from the dataset.

- Build a content-based recommendation system to suggest movies similar to a user's favorite title.

## Implementation Details:
- `Preprocessing`: Handled missing values and outliers, and added 7 new features to support analysis, including: **month_added, year_added, has_seasons, duration_minutes, duration_category, content_type, and region.**

- `Data Visualization & Analysis`: Conducted analysis from three key perspectives: time series trends, geographical distribution, and content characteristics/genres.

- `K-Means Clustering`: Grouped movies based on shared attributes using the K-Means algorithm. These clusters were further analyzed to extract valuable insights.

- `Recommendation System`: Developed a content-based recommendation system to suggest similar titles based on a user's preferred movie.
